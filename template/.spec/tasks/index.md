## 写卡规则

1. **一卡一目录**：`.spec/tasks/<ID>/card.md`（背景/范围/验收）+ `log.md`（执行流水）。
2. **ID 不复用**：`T1`、`T2`……；跨波次继续递增，不要每个波次从 T1 重新开始。
3. **`scope` 必须写**：允许改的路径。没写 = 默认不许动任何代码。
4. **`accept` 必须可验证**：不是"功能上线了"，是"怎么证明做完了"。
5. **卡完成后**：`log.md` 写清最终方案与 commit，索引状态改 `done`。整波完成后，将该波次所有任务目录移动到 `archive/W<n>/`，并在归档索引登记；禁止只归档一行摘要而丢失卡片与流水。
