## 写里程碑的规则

1. **一个里程碑一个目录**：`.spec/roadmap/<ID>/milestone.md`。
2. **判定标准**：一件事如果"一个人几天能做完"，它是卡；如果要拆成好几张卡，它是里程碑。
3. **不写日期估算**：只写顺序和依赖。没实测数据前的估时都是编的。
4. **必须写 Non-goals**：这一阶段主动放弃什么、为什么。这比"要做什么"更能防返工。
5. **完成判据要能验证**：不是"功能上线"，是"某个数字达到某个值"或"某个流程能跑通"。
