## 3. 发布前检查

- [ ] 治理检查通过
- [ ] 本项目定义的构建、lint、类型检查与测试命令已实际执行；未执行项明确标记为 `unverified`
- [ ] 类型检查 / lint 通过
- [ ] 构建成功，产物目录里只有一个版本
- [ ] 从产物启动，确认读的是正确的数据/配置目录
- [ ] 若改过应用标识（包名、appId、模块名）：确认数据迁移逻辑覆盖了新名字
- [ ] 版本号与 git tag 一致

## 4. 版本号

`MAJOR.MINOR.PATCH`：功能涨 MINOR，修 bug 涨 PATCH。
**改应用标识属于 MAJOR 级变更**——会动用户数据目录，必须带迁移。
