# ADR — 架构决策记录

> 只在**推翻既有设计**或**在两条红线之间做取舍**时写。小的实现选择不进这里。
> 命名：`ADR-<三位序号>-<短标题>.md`，一页以内。

## 模板

```markdown
# ADR-00X 标题

- 日期：YYYY-MM-DD
- 状态：accepted | superseded by ADR-00Y

## 背景
什么情况下必须做这个决定？（写事实，不写立场）

## 决定
一句话说清选了什么。

## 放弃的方案
至少列一个被否掉的，并说明否掉的具体理由。

## 代价
这个决定让什么变差了？诚实写。

## 依赖前提
如果这个前提不成立，本决定需要重审。
```
